# English Learning Method — Multi-Context Vocabulary

## Goal

Build **active English** for thinking, speaking, listening, reading, and writing.

**Situation / idea → English**

Not:

**Situation / idea → another language → translate → English**

## 1. Learn words through contexts, not translations

Do not learn isolated equations such as `get = ...`, `take = ...`, or `make = ...`.

Instead, learn one high-frequency word across many real contexts.

Example with **GET**:

- get an email
- get tired
- get home
- get something
- get it
- get a chance
- get ready
- get better
- get back to someone

Understand what the word means **inside each context**.

## 2. Learn chunks and collocations

Treat common expressions as one unit:

- **Let me take a look.**
- **That makes sense.**
- **I'll get back to you.**
- **I have no idea.**
- **I'll do my best.**

Do not build these sentences word by word while speaking. Retrieve the whole chunk automatically.

## 3. Connect contexts with a core idea

Do not memorize unrelated dictionary definitions. Understand the mental connection between uses.

Example: **GET** often involves movement or change:

- `get an email` → something comes to you
- `get tired` → change of state
- `get home` → arrive somewhere
- `get better` → change/improvement
- `get it` → move from not understanding to understanding

This creates a semantic network around the word.

## 4. Use many real-life contexts

### Daily life

- food
- travel
- shopping
- friends
- home
- feelings
- routines

### Work

- meetings
- tasks
- email
- technical issues
- decisions
- communication
- deadlines

Prefer sentences that could actually occur in real life.

## 5. Learn through Question → Answer conversations

Example with **DO**:

**Q:** What are you doing?  
**A:** I'm doing some work.

**Q:** Do you think you can finish today?  
**A:** I'll do my best.

**Q:** Can I do anything to help?  
**A:** Actually, can you do me a favor?

This teaches vocabulary as part of conversation rather than isolated sentences.

## 6. Compare similar high-frequency words

- **I got some coffee.** → obtained/bought it
- **I made some coffee.** → prepared it
- **I had some coffee.** → drank it

Work example:

- **I have a problem.**
- **Let me take a look.**
- **I need to make some changes.**
- **I'll get back to you.**

Vocabulary should become a connected network.

## 7. Use English-only explanations

During English-learning sessions:

- Use English only.
- Explain difficult ideas with simpler English.
- Avoid translation unless specifically requested.
- Focus on understanding from context.

This supports **thinking directly in English**.

## 8. Use all language skills

### Read
Read natural examples in different contexts.

### Listen
Notice the word and its chunks in natural speech.

### Speak
Say the chunks and sentences aloud.

### Write
Create sentences related to realistic daily-life and work situations.

### Think
Use the word during English inner speech/self-talk.

The target is **active retrieval**, not passive recognition.

## 9. Personalize sentences

Prefer first-person sentences that can map to a real situation:

> I have a meeting this morning.

instead of named textbook characters.

Prefer:

> I need to make some changes to the API.

when it represents a realistic work situation.

Personal relevance makes vocabulary easier to retrieve later, but examples should not expose identifying information.

## 10. Build English inner speech

- **I need to get ready.**
- **I've got a lot to do.**
- **Let me check.**
- **That doesn't make sense.**
- **Let me take a look.**
- **I'll deal with it later.**

If a word is missing, describe the idea using English instead of immediately translating. This is **circumlocution**.

## 11. Prioritize high-frequency, high-utility words

Learn fewer words deeply rather than many words superficially.

Example starter sequence:

1. **GET**
2. **TAKE**
3. **MAKE**
4. **HAVE**
5. **DO**

Continue with common words that appear across many daily and work contexts.

## 12. Lesson format

Each vocabulary lesson should contain:

1. **One high-frequency word**
2. A short explanation of its core idea
3. **Many useful contexts**
4. Several natural examples for each context
5. Explanation of **why the word works in that context**
6. Important chunks/collocations
7. Daily-life examples
8. Work examples
9. **Question → Answer** conversational examples
10. Comparisons with previously learned words when useful

Do not add a detailed study plan or quick-practice section unless requested.

## Core principle

**context → meaning → English chunk → automatic use**

A word is truly useful when it can be understood and produced naturally across different situations without first translating from another language.
