# Source Policy

## Project sources

Project sources define the learner's curriculum and preferred method. Use them before external research.

## Language usage

When checking modern usage, prefer reputable corpus, dictionary, and editorial guidance. Avoid treating any crowd-sourced sentence as authoritative.

## Learning science

Prefer university learning centers and peer-reviewed evidence. Favor retrieval practice, spaced practice, interleaving, contextual learning, and productive recall when they fit the lesson.

## Technical sources

Preferred order:

1. Microsoft Learn / Azure Architecture Center / official .NET docs
2. Official Angular docs
3. Official GitHub repositories
4. Mature maintained third-party repos

Do not rank technical truth by stars alone. Stars are only a community-adoption signal.
