# Private English Learning Log

Copy this template to `private/english-learning-log.md`. Keep real learner state out of Git and the public site. This is a blank template, not a completed lesson record.

```yaml
lesson_id: <existing lesson ID>
attempted_on: YYYY-MM-DD
lesson_key: <existing lesson key>
produced_correctly: []  # chunk IDs actually produced without reading a model
needed_hints: []       # chunk IDs that needed help
errors_to_revisit: []  # only useful learning notes; omit personal details
mastery: null         # 0–4 only after an actual attempt
successful_on: null   # first successful unassisted use; not the publication date
next_review: null     # based on observed retrieval, not merely reading
```

## Mastery scale

- **0:** Could not understand or use the language.
- **1:** Needed strong hints.
- **2:** Produced language with hesitation or errors.
- **3:** Produced it correctly in a familiar situation.
- **4:** Used it naturally across multiple new situations.

Reading a sample or finishing a page does not establish mastery. Retry weak chunks with a new situation. Default successful-review offsets are 1, 3, 7, 14, 30 and 60 days; failed retrieval brings review closer.
