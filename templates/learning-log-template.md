# English Learning Log

Use one entry per completed lesson.

## Entry template

```yaml
lesson_id: EN-YYYYMMDD-slug
date: YYYY-MM-DD
track: work-communication
anchor: clarify / clarification chunks
lesson_key: work.meeting.clarify-requirement
topic_tags:
  - meeting
  - requirement
  - clarification
new_chunks:
  - Just to clarify, ...
  - Do you mean ...?
  - If I understand correctly, ...
source_types:
  - project
  - microsoft
mastery: 3
weak_points:
  - article usage
  - follow-up question speed
review_due:
  - YYYY-MM-DD
  - YYYY-MM-DD
```

## Mastery scale

- 0: could not recognize/use it
- 1: recognized with strong hints
- 2: produced with hesitation or errors
- 3: produced correctly in a familiar situation
- 4: produced naturally across multiple new situations
