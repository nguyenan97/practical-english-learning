## How to use this reference

Treat the document as a **candidate phrase bank**, not as authoritative modern-English guidance.

Before teaching a phrase:

1. Check whether it is still natural in current English.
2. Correct grammar, spelling, punctuation, or dated wording when necessary.
3. Prefer the modern natural form while preserving a note when the source form differs.
4. Teach the phrase in context rather than as an isolated translation pair.
5. Turn useful phrases into Q → A dialogue, retrieval prompts, and personalized examples.

## Representative high-utility patterns

The source contains many useful communicative functions such as:

- asking someone to repeat or speak more slowly;
- asking for directions;
- making a reservation;
- asking prices and payment questions;
- ordering food and drinks;
- asking for help;
- handling phone calls;
- talking about time and schedules;
- introducing yourself and making small talk;
- discussing work;
- describing health problems and emergencies;
- talking about weather.

These functions are better used as lesson anchors than memorizing the source sequentially from page 1 to page 28.

## Quality note

The source contains wording that may be dated, unnatural, misspelled, or context-dependent. For example, the learning workflow should verify source phrases against reputable modern usage before presenting them as recommended English.
